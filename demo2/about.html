About BrickMMO Analytics

Understanding our comprehensive tracking system

What We Track

Technical Information

Browser & Version: Detect Chrome, Firefox, Safari, Edge, Opera, and other browsers

Operating System: Windows, macOS, Linux, Android, iOS with version details

Screen Resolution: Monitor display capabilities and device types

Viewport Size: Track window dimensions for responsive design insights

Color Depth: Monitor display color capabilities

User Behavior

Page Views: Track which pages users visit and how often

Session Duration: Monitor how long users stay on your site

Referrer Sources: See where your traffic comes from

Navigation Patterns: Understand user journey through your site

Return Visits: Track user retention and loyalty

Geographic & Language Data

Timezone: Automatic detection of user's timezone

Language Preferences: Browser language settings

Regional Patterns: Understand your global audience

Time-based Analytics: Peak usage hours and patterns

System Capabilities

JavaScript Enabled: Verify client-side functionality

Cookies Support: Track cookie acceptance and preferences

Java Support: Legacy plugin detection

Online Status: Network connectivity monitoring

Integration Methods

Data Attributes

Simple integration using HTML data attributes on the script tag. Perfect for quick setup and multiple asset tracking.

<script src="tracker.js" data-asset-id="2"></script>

Global Variables

Configure tracking through JavaScript global variables for more dynamic setups and runtime configuration.

window.BRICKMMO_ASSET_ID = 2;

URL Parameters

Pass asset ID through URL parameters for testing and development environments.

example.com?asset_id=2
